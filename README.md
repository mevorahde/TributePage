# Jerry Rice Tribute Page

This repository preserves a Jerry Rice tribute-page exercise completed for
freeCodeCamp's Responsive Web Design curriculum in 2018. It is a static HTML
and CSS learning project focused on page structure, images, timeline content,
and external reference links.

## View the page

Open the [published tribute page](https://mevorahde.github.io/TributePage/) or
open `index.html` locally in a browser.

## Status and attribution

The project is retained as a historical learning artifact and is not actively
maintained. It is an independent fan-created exercise and is not affiliated
with or endorsed by Jerry Rice, the San Francisco 49ers, the NFL, or
freeCodeCamp. External facts, images, and links remain attributable to their
respective sources and may have changed since the page was created.
